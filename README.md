# stopwatch_app.github.io
For this project, I created a web app for users to keep track of their work time on their different projects. 

It aims to provide an answer to the infamous 
  *Wow, how long did it take you to crochet that blanket?*
  or
  *You must have spent at least 24 hours working on that table in the workshop!*
  
The app utilizes Python, JavaScript, HTML, and CSS.

## Features
*Secure credential storage using bcrypt to hash and salt passwords
*A stylized stopwatch to track work sessions 
*Custom, user-created project items which display total work time and number of work sessions
*A statistics page where users can see total stats about their projects as well as details of individual work sessions
*Export options for statistics as CSV or PDF
*Optional tracking of multiple projects at once in different tabs
